# SauceDemo E2E UI Tests

Реализация автоматизированного сквозного сценария покупки товара на сайте [SauceDemo](https://saucedemo.com) в паттерне Page Object Model (POM).

## Стек технологий
*   **Язык:** Python 3.11+
*   **Инструменты:** Playwright (Sync API), Pytest
*   **Пакетный менеджер:** `uv` (от Astral)

---

## Варианты запуска

### Вариант 1: Запуск через Docker (Рекомендуемый)
Тесты запускаются в изолированном Linux-контейнере. Графический интерфейс отключен (`headless` режим).

```bash
docker compose up --build
```

### Вариант 2: Локальный запуск (через `uv`)
При локальном запуске по умолчанию открывается графическое окно браузера Chromium (`headed` режим).

1. Установите менеджер пакетов `uv`:
   ```bash
   pip install uv
   ```
2. Разверните виртуальное окружение и установите зависимости:
   ```bash
   uv sync
   ```
3. Скачайте бинарные файлы браузера:
   ```bash
   uv run playwright install chromium
   ```
4. Запустите тесты:
   ```bash
   uv run pytest
   ```
